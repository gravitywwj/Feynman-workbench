# 费曼学习工作台：修改后产品体验复查

复查日期：2026-08-12

## 结论

上一轮的主要 P0 已基本落地：新版首页突出“今天的下一步”，诊断结果结构化，二次表达与学习结果闭环可完整完成，移动端主按钮不再裁切，掌握度、复习计划、图谱推荐、资料设置和 Obsidian 入口也已出现。

产品已经从“功能原型”进入“核心体验可用”阶段。下一轮最重要的不是继续增加模块，而是提高核心判断的准确性和推荐的可解释性，并降低移动端导航与大图谱的认知负担。

## 已确认改善

1. 首页只突出一个建议任务，首次进入比旧版清楚。
2. “讲解 / 回顾 / 表达 / 复述”已收敛为“回忆表达 → 盲区诊断 → 简化复述”。
3. 诊断结果拆为“已讲清楚 / 盲区 / 下一任务”，信息更易扫描。
4. 可完成第二次表达，并比较两次表达、查看次日复习和推荐概念。
5. 移动端学习笔记与开始回忆表达改为纵向全宽按钮，没有页面横向溢出。
6. 状态按钮已有 `aria-pressed`，步骤已有 `aria-current`，图谱提供键盘可用的列表替代视图。
7. 资料配置界面解释了本地保存和 AI 文本发送边界，并提供两分钟示例。

## 剩余 P0

### 1. 核心诊断仍有明显误判

本次测试回答明确给出“应用提供 schema → 模型返回 tool_calls → 应用校验并执行 → 结果回传模型”，并补充工具权限、非法参数、超时与提示注入，但本地诊断仍判定“关键机制不够明确”。第二次表达进一步简化因果关系后，结果页仍保留同一盲区。

这是当前最重要的风险：如果用户认为自己讲清楚了，而产品仍给出模板化否定，信任会迅速下降。

建议：

- 本地模式明确改名为“表达结构提示”，不要称为盲区诊断；
- 将规则从关键词长度升级为可解释的结构证据，逐项显示检测到的句子；
- 第二次表达后重新评估盲区，允许“已改善 / 仍不足 / 用户标记误判”；
- 建立真实回答评测集，记录假阳性、假阴性和用户驳回率。

### 2. 推荐下一概念缺乏理由

结果页直接推荐“qmd 工业级混合检索管线精讲”，没有说明它与当前 function calling 的关系，也没有解释为什么比修复当前盲区更优。首页推荐同样缺少来源依据。

建议每个推荐至少说明一种理由：知识链接、学习路径顺序、薄弱邻居、到期复习或用户目标；如果只是按“最弱优先 + 标题排序”，不要包装成个性化推荐。

## P1

### 1. 移动端顶部导航仍然费力

虽然主 CTA 已修复，但品牌被压成多行竖排，顶部模块依赖横向滚动，用户只能看到部分入口。建议在手机端保留产品标识和一个“更多”入口，把“今日 / 图谱 / 复习”放到底部导航，夜间阅读与资料设置归入菜单。

### 2. 移动端图谱仍不是有效决策界面

手机端图谱首屏先显示大块画布，推荐卡和键盘列表在下方。49 个节点在窄屏上非常拥挤。建议手机端默认进入列表式“下一步建议”，图谱作为二级切换；默认只显示当前节点的一到二跳邻居。

### 3. “新收录 68 条”仍占据大量注意力

全部笔记同日导入导致“最近新增”长期占满右栏。建议聚合为“8 月 12 日导入 68 条”，或只显示导入后真正新增的条目；用户完成一次学习后，右栏应优先显示“继续补充盲区”和“明日复习”。

### 4. 学习结果需要反映二次表达的改善

当前结果页对比两次文本，但没有标记第二次具体改善了什么。建议展示“新增的关键因果、删除的冗余术语、仍未覆盖的事实”，让用户感受到二次表达的价值，而不只是看到两段文字。

### 5. 设置入口仍是路径文本框

相较环境变量已经进步很多，但普通用户仍需理解“Wiki 根目录 / pages”。桌面应用最终应提供系统文件夹选择器，并用预览确认选中的资料；错误状态说明不会读取哪些目录、不会改写哪些文件。

## P2

- 推荐任务增加“换一个”和目标筛选，例如考试、项目汇报、长期掌握。
- 学习时长从占位符变成真实会话时间，否则移除。
- 图谱区分“阅读状态”和“掌握状态”，避免图例仍只呈现未读 / 在读 / 已读。
- 周报和掌握度在有足够学习证据前展示解释性空状态，避免过早形成虚假精确感。
- Obsidian 插件增加服务未启动、Wiki 不匹配和页面不在 `pages/` 中的可恢复提示。

## 审查步骤与健康状态

1. 新首页：单一任务清楚，推荐依据不足。状态：基本健康。
2. 推荐主题与阅读：主入口明确，右栏仍偏拥挤。状态：健康。
3. 回忆表达入口：语气和任务清晰，支持口述。状态：健康。
4. 结构化诊断：布局明显改善，但发生核心误判。状态：高优先级风险。
5. 第二次表达与结果：闭环完整，未重新判断改善。状态：基本健康。
6. 手机端主题页：CTA 修复且无横向溢出，顶部导航仍拥挤。状态：基本健康。
7. 图谱决策：新增推荐与列表替代视图，移动端画布优先级不当。状态：需优化。
8. 资料与设置：隐私说明和示例入口清楚，文件夹选择仍偏技术化。状态：基本健康。

## 证据限制

本轮未测试真实 AI 深度诊断、浏览器语音识别授权与转写质量、多日复习调度、Obsidian 内实际安装、屏幕阅读器或 200% 缩放，因此不能据此声称完整可访问性或长期学习效果。复查产生的本地测试会话、卡片、盲区和学习事件已清理。
