日期：2026-10-16，Asia/Hong_Kong。

## 1. 产品目标与首版边界

将费曼学习工作台升级为个人 AI 工程学习实验室，在同一页面完成：学、讲、写、跑、调试、挑战、整理、接续。费曼方法继续承担理解检查；课程、实验和成长机制组织持续学习。

借鉴 Codédex 的章节、短任务、项目、XP、等级、徽章、解锁与站内编辑器。视觉采用清晰、紧凑的工程工具界面，趣味来自可操作的实验、任务推进和可保留的作品。Linear / Raycast 作为信息密度与操作反馈的参考，不复制其界面或资源。

AI Engineering Learning OS 是长期产品定位。首版界面名称采用 AI Engineering Learning Lab；本次不迁移仓库目录、数据库文件或既有 Wiki 路径。

首版只接入 ai-engineering-from-scratch 一门课程，交付 RAG / Retrieval Evaluation 的三个 Mission、一次 Boss Project，以及对应地图、成长反馈和知识草稿。其他章节可展示课程目录与可读资料，未适配实验明确标为“实验待适配”，不能显示可运行或已完成。

当前用户已明确接受 XP、等级、徽章和解锁。这些机制纳入首版；既有产品文档中偏向纯工具的表述在实施时同步更新。保留来源核对、独立作答与间隔复测规则。

首版不包含排行榜、断签惩罚、签到强提醒、角色换装商城、复杂剧情、多人社区、通用 IDE、自由命令终端、GPU 训练或多 Agent 编排。

| 区域 | 内容与行为 |
| --- | --- |

| 右侧上部 Lesson / Mission | 具体故障、要弄清的问题、必要资料、预测、费曼复述和分级提示 |

左侧地图保持窄栏；右侧学习区与实验区上下分布，可切换学习聚焦或实验聚焦。地图折叠后允许学习与实验左右并排，避免长期挤压代码区域。窄屏切换“任务 / 实验 / 记录”，保持同一来源与草稿。

全局只保留一套当前任务上下文。点选错误、结果或代码片段时，向同一个学习助手提供明确引用；不增加彼此割裂的 Tutor、代码助手和知识助手聊天窗口。

XP 总量、当前等级、升级所需 XP 和章节进度分别标注。进度条有明确分母，例如“本章任务完成 3/4”；等级进度按本级 XP 计算。Agent Engineering 是当前路线名称，不由活动 XP 自动生成工程师能力称号。

节点至少区分未开始、进行中、任务完成、需复查。使用文字与形状辅助颜色。每个任务结束可保存并离开，保留继续入口；不自动跳入下一题或发起下一轮付费模型调用。

保留现有明暗主题、阅读设置和清晰字体。动效只表达运行、状态变化与完成反馈，支持减少动效；首版不增加音效或装饰性角色养成。

## 4. Mission、挑战与解锁

Mission 必须包含：一个具体问题、预期现象、可修改对象、运行前预测、运行后观察、明确验收条件和个人解释。只把 Exercise 改名不构成交付。

| 首版任务 | 操作与可见结果 | 验收范围 |
| --- | --- | --- |
| Mission 01：找回遗漏的证据 | 调整 Top-K，对比命中、干扰与遗漏文档；预测 precision / recall 的变化 | 在指定数据上实现正确计算，并解释实际结果；不保证 Top-K 增大时 precision 必然下降 |
| Mission 02：修复失真的排名评价 | 阅读并修复排名指标实现，用固定测试暴露对相关文档名次的错误评价 | 指定正常与边界样例通过，展示同一检索结果在修复前后的评价差异及原因 |
| Mission 03：识别平均分背后的退化 | 比较两套检索结果，展示总体指标和逐查询差异 | 正确标出回归查询，解释整体改善与局部退化为何能同时出现 |
| Boss：交付 Retrieval Evaluation Lab | 使用课程已有 staged starter、grader 和新评估输入，输出可复现对比报告 | 精确率/召回率、排名指标、回归检测及报告标准逐项通过；保留命令、版本、代码、输入与结果 |

以上是待适配的任务定义。实施时读取固定课程版本，确认 starter、grader 和具体课时契约；没有对应现成步骤的部分只增加必要教学任务与测试，不宣称课程原本提供了该 Mission。Boss 的首版范围是检索评估，不扩展成需要模型、Embedding 服务及向量数据库的完整 RAG 系统。

资料阅读与预览自由进入；地图提供顺序和前置说明。独立挑战的验收资格由服务端检查具体前置证据。已熟悉的内容可以直接尝试挑战；一次直接挑战通过只完成该挑战，不伪造未做过的 Mission 记录或奖励。

提示按方向、概念、局部代码、完整解法逐级展开。每次使用保存帮助程度；实际查看参考解答或应用 AI 补丁后不能改回“无帮助”。工作台记录的无帮助状态仍包含用户自述，界面不声称证明了外部未使用帮助。

同题重做标明重做。Boss 的练习、首次挑战、新输入变式与延迟复测分别记录。新输入必须改变问题或数据且有相应标准；只改题目名称或随机顺序不算变式。最近一次有效失败显示需复查，保留历史成功，不能用历史成功掩盖当前问题。

任务完成定义为“该版本的指定标准通过，并保存必要的预测、观察和解释”。帮助后通过可以完成学习任务，界面附帮助记录。独立挑战通过另行显示；测试通过不会单独证明解释正确、能力迁移或长期保持。

## 5. XP、等级、徽章与费曼检查

首版采用固定奖励，不增加通用成就规则引擎：每个 Mission 首次完成 +100 XP；每个 Mission 首次完成一次费曼表达、反馈和修订记录 +80 XP；Boss 首次满足项目验收标准 +500 XP。学习等级 = 1 + floor(累计 XP / 500)。数值属于产品初始参数，不代表学习效果已经验证。

XP 是学习活动反馈。费曼环节的 +80 XP 表示完成表达与修订过程；离线或事实未核验时仍明确标为待核对。不能显示“Concept Mastered”或以 AI 给出 4/5 作为掌握、来源核对或通关的唯一条件。

费曼检查优先展示：定义/目标、因果机制、具体例子、边界条件、实验解释中的证据与缺口。禁用几个术语可以成为表达练习，但不能成为事实正确的判定标准。AI 核对保留资料引用，失败或缺少依据时不产生已核对证据。

XP 和能力证据互不替代。原有来源核对、应用、变式、延迟和保持状态继续独立计算。代码测试新增为“指定测试通过”的证据，不直接写成 source_reviewed；AI 补丁和指导记录不会被统计为独立完成。

XP 由后端根据实际记录发放。奖励事件使用稳定的课程、任务和奖励类别唯一键；奖励与完成状态在同一事务保存。刷新、重试、并发、重复导入、改任务版本都不能重复发奖。修改任务版本不清空已领奖状态；需要独立新挑战时创建真实的新任务身份。

首版 Boss 徽章为“检索评估项目 v1”，从合格项目记录派生，附代码、grader 版本和帮助程度。徽章表示完成过该项目；最新复测失败或来源变化时同时显示需复查。它不等价于“已成为 RAG Engineer”。历史学习数据保留，不自动追发未经定义的 XP。

## 6. 课程、记录与代码归属

| 对象 | 保存与边界 |
| --- | --- |
| 课程源 | 本地只读课程仓库，保存来源 URL、commit、课时相对路径；原文和许可保留 |
| 课时与任务 | 稳定 course_id / lesson_key / mission_key；版本单独记录，可选关联 Wiki 页面 |
| 学习断点 | 继续保存于工作台 SQLite，扩展来源身份；不另建第二份权威进度文件 |
| 实验文件 | 独立实验目录；每次运行保存有限大小的文本代码快照与哈希 |
| 运行记录 | 服务端生成 UID，记录输入、代码、命令、cwd、退出码、标准版本、逐项结果和帮助记录 |
| XP | SQLite 奖励事件去重；等级和徽章从记录推导，不由浏览器提交结论 |
| 知识成果 | 本地草稿、来源和修订历史；确认后进入现有 Wiki 维护流程 |

学习来源扩展为 Wiki 页面或课程课时，旧 page_path 调用继续兼容。没有 Wiki 关联的课程记录不伪造页面路径、不混入 Wiki 孤立记录，也不被页面重关联逻辑覆盖。绑定 Wiki 后关联已有证据引用，不能复制记录制造二次完成或奖励。

按实际需要增加课程断点、任务尝试、代码运行和奖励事件记录，复用现有会话、笔记和事务工具。无需通用任务调度框架、事件总线、向量数据库或第二套记忆服务。

课程原文与第三方说明作为学习资料处理；执行命令和验收标准来自明确审查、固定版本的适配配置。浏览器、模型输出和可编辑实验文件不能修改 grader 或声称自己通过。界面区分基础测试、未见输入及参考解答；不默认显示验收答案。

备份升级为新版本，继续接受历史版本 1–8。包含课程定位、草稿、代码文本快照、运行历史和奖励事件，不包含密钥、解释器环境、整份课程仓库或任意外部路径。按当前 JSON 备份结构保存受限文本产物即可，暂不做任意二进制归档。

导入校验字段、数量、大小、相对路径与哈希，按稳定 UID 去重；不接受客户端累计 XP，不从一段导入的“测试通过”文本补发奖励。导入结果保留 imported 来源标记，不能冒充本机新执行证据。导入不运行代码、不安装依赖、不自动升级信任或覆盖有更新的实验草稿；先展示冲突预览。

## 7. 执行与个人 Agent 接入

个人 Agent 保留主循环、上下文选择、Memory Gate 和审批。工作台持有权威学习记录；Codex 是代码任务执行端，费曼反馈复用现有服务。通过当前 learning 插件和项目连接器增加必要接口，不再创建独立的 lesson_agent / quiz_agent / knowledge_agent。

工作台本机后端代理个人 Agent 的当前 Mission 请求与运行事件，前端不获取模型凭证。每次只发送指定课时、当前输入、选定代码片段与运行快照；任务默认不读取其他会话、Personal Wiki、账本或工作项目。明确显示正在解释哪个版本的代码或运行结果。

工作台实验服务持有唯一的运行与测试入口。Personal Agent 通过该接口发起或读取实验，不再维护第二套执行器、grader 或实验进度；个人 Agent 离线时，本地实验仍可使用已验证的运行入口。

Codex app-server 用于可恢复代码会话和受控执行。优先验证 command/exec 的沙箱执行能力；thread/shellCommand 与 process/spawn 不作为实验运行入口。依据本机协议生成工具核对实际字段，不把在线文档等同于已安装版本支持。

开放代码执行前必须通过以下检查：

- 只允许后端生成的命令参数，命令、运行时和 grader 受信；不向前端开放任意 shell 字符串。
- 实际限制读取范围、写入目录与网络；只读课程和必要运行时可访问，Wiki、工作项目、宿主密钥与敏感环境变量不可访问。限定 cwd 不能替代隔离。
- 解析最终绝对路径并处理父目录穿越、符号链接、junction 和 Windows 路径边界；每次运行使用代码快照，grader 保持只读。
- 默认关闭实验联网，环境变量采用最小允许集合。沙箱与资源配额分别处理，适配层补足超时、输出上限、并发限制及子进程回收；终止、超时和服务崩溃可恢复为明确状态。
- 新执行与 Agent 操作接口只监听本机，校验 Host / Origin 与本机授权，防止网页跨站触发操作；不能只依赖“服务在 localhost”。
- Windows 隔离或协议验证失败时保持运行不可用，并给出可恢复错误；不能回退为同用户权限裸 subprocess。

运行状态至少包含排队、执行中、成功退出、失败退出、超时、取消和中断。进程退出 0 与测试标准通过分开表示。后端启动成功、连接成功、模型推理成功和沙箱可用分别检测，不能互相替代。

AI 补丁先显示差异，由用户应用；应用前比较当前代码哈希，冲突时保留两份内容并重新生成差异。修改后旧结果明确标为历史版本，不自动当成当前代码通过。

未启用模型仍可阅读、编辑、保存及在已验证运行环境中执行固定测试；自然语言事实检查标为待核对。个人 Agent 离线不阻断本地学习与已有记录，界面明确显示离线能力边界。

## 8. 知识整理与边界

收尾草稿包括：我现在的理解、最初误解、代码修改、实际结果、因果解释、未解决问题、资料出处和下次起点。未核对内容保留待验证状态，不把全部课程原文、聊天或输出自动灌入 Wiki。

已有 Learning Wiki 页面继续使用工作台现有审核、差异确认、来源变化检查与撤销；扩展课程来源证据适配时保留这些门槛。来源、目标页面或代码证据在审核后变化，原审核失效。无法匹配可靠资料时只保存本地草稿或待验证内容。

新增知识页走 Learning Agent 维护清单与其规则。Personal Agent 不直接批量改写 Learning Wiki，学习路线不默认连接或回灌 waste-compliance-agent，不混入工作项目资料。个人长期记忆仍走现有 Memory Gate。

| P5 | 备份与完整回归 | 导入导出、断线恢复、旧学习流程、边界测试和实际 UI 验证通过 |

只完成静态地图、假运行、XP 动画或部分接口不能宣称首版完成。实施时每个工作包保留其必要测试，不为低影响文案/样式变化制造镜像测试。

## 10. 首版验收清单

1. 新用户从地图进入一个 Mission，在一个页面完成阅读、预测、复述、编辑、真实运行、解释、查看奖励及保存断点；离开后可继续。
2. 三个 Mission 和 Boss 均有真实标准、失败样例及可重现通过样例；针对用户代码使用只读 grader，不能靠篡改前端或输出文本取得通过。
3. 网络、资料、代码、测试失败时展示实际状态；固定测试通过、AI 核对、独立挑战与长期保持互不冒用。
4. 连续提交、刷新、并发、服务重启、重复导入及任务版本更新均不会重复发放 XP；徽章可回到对应版本作品和证据。
5. 查看提示、参考解答或应用 AI 补丁后，帮助记录正确保留；未见输入、变式与延迟资格由后端计算。最近有效失败能显示需复查。
6. 越界路径、junction、敏感文件读取、联网、宿主环境变量泄漏、输出洪泛、超时和取消行为经过 Windows 实测；没有权限自动扩张或裸进程回退。
7. 运行结果与代码版本匹配；旧结果不会随编辑自动升级为新结果。补丁冲突、草稿冲突与页面来源过期均可恢复且不丢失用户输入。
8. 新旧备份往返保留课时记录、代码快照、帮助记录和 XP 去重；不导出密钥、不执行导入代码、不覆盖未处理冲突。
9. 既有 Wiki 学习、单卡复习、来源核对、应用自测、心得、推荐、图谱、写回及撤销回归通过；课程记录不污染 Wiki 路径统计或个人/工作空间。
10. 桌面与窄屏验证地图折叠、任务切换、长代码、长输出、键盘操作、焦点、主题和减少动效；每个任务可直接结束，不自动继续付费调用。

完整交付报告包含实际版本、测试结果、可复现运行与界面证据、已知限制及未验证项。浏览器或沙箱无法验证时按未完成项报告。
